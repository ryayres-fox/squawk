# Squawk

A local, single-user, read-only orchestrator for open-source security scanners.
Evidence-first, loopback-only.

## This repository is not released yet

It is a placeholder holding the licence and nothing else. The application is
still developed in a private repository and will be ported here once two gates
are met:

1. **Every service validated on real data.** Thirteen services; the three that
   drive a running app (`recon`, `liveprobe`, `activeprobe`) are the last to be
   exercised.
2. **A publication pass.** The working record — changelog, worklog, plans — is
   written against a real estate and does not cross. What lands here is written
   from public standards against synthetic targets.

Until then there is nothing to clone. Licensed Apache-2.0.
